## Non-Negotiable Cross-Cutting Requirements

- one authoritative biological core;
- deterministic supported mode;
- explicit matter and energy;
- local information;
- analytical labels remain noncausal;
- organic non-grid normal view;
- save/load equivalence;
- stable IDs and ancestry;
- intervention provenance;
- evidence-based explanations;
- performance limits remain technical;
- full explicit simulation precedes abstraction;
- packaged-runtime and human QA acceptance.
