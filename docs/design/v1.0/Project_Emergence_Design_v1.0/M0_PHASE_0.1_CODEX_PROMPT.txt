`self-test` must run a small deterministic nonbiological foundation test that does not duplicate Phase 0.2 domain work. Appropriate checks include:

- no culture-dependent output for the test vector.

Exit codes:
- 0: all required checks pass;
- nonzero: required check fails;
- warnings alone do not produce a success claim without being listed.
