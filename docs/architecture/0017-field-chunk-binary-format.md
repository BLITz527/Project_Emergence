# ADR 0017: Field chunk binary format V1

Status: Accepted for Milestone 1 Phase 1.1

## Decision

Large field amounts are encoded in bounded `.bin` chunks, never JSON arrays. `PE-FIELD-CHUNK1\0` identifies the format. Numeric fields are explicit little-endian; RegionId and digests use canonical displayed byte order. Headers bind region, chunk coordinate/dimensions, region-definition digest, and channel-catalog digest. Each channel then stores its strict UTF-8 ID and local row-major UInt64 amounts.

## Consequences

Wrong magic, metadata, channel order, dimensions, solid matter, truncation, trailing bytes, or limits fail closed. The reference four lengths/hashes are locked in `docs/phase-1.1-traceability.md` and independently generated by `tools/reference/phase11_environment_vectors.py`.
