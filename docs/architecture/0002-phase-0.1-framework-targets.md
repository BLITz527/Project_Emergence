# ADR 0002: Phase 0.1 framework targets

Status: Accepted with Godot verification pending

## Context and evidence

Preflight found Windows 10 build 22631 x64, .NET SDK 10.0.201, and no preview SDK. The installed SDK's current xUnit template targets `net10.0`. No Godot executable was available, so the target normally generated by Godot 4.7 could not be observed locally.

## Decision

`global.json` selects SDK 10.0.201 with latest-patch roll-forward and prerelease disabled. All authored projects target `net10.0`; the Godot project uses `Godot.NET.Sdk/4.7.0`. This provides one coherent target and avoids preview frameworks.

## Compatibility and trigger

The headless target is verified by build and test evidence. Godot compatibility is provisional until a Godot 4.7 stable .NET editor builds, loads, and exports the project. If that editor requires an earlier stable target, move the App and all shared projects it references to the newest mutually supported non-preview target, record the exact editor-generated baseline and reason here, and rerun the full acceptance suite.
