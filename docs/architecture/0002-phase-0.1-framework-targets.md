# ADR 0002: Phase 0.1 framework targets

Status: Accepted

## Context and evidence

Initial preflight found Windows 10 build 22631 x64, .NET SDK 10.0.201, and no preview SDK. The installed SDK's current xUnit template targets `net10.0`. Follow-up verification used Godot `4.7.stable.mono.official.5b4e0cb0f` with matching `4.7.stable.mono` .NET export templates.

## Decision

`global.json` selects SDK 10.0.201 with latest-patch roll-forward and prerelease disabled. All authored projects target `net10.0`; the Godot project uses `Godot.NET.Sdk/4.7.0`. This provides one coherent target and avoids preview frameworks.

## Compatibility evidence and trigger

The headless target is verified by build and test evidence. Godot 4.7 stable .NET successfully built and loaded the project, initialized and visibly rendered the normal shell, produced App diagnostics, exported Windows x86_64, and ran packaged smoke and diagnostics with `net10.0`. If a future stable Godot release requires a different target, move the App and all shared projects it references to the newest mutually supported non-preview target, record the exact baseline and reason here, and rerun the full acceptance suite.
