# Milestone 0

## Phase 0.1 — foundation shell and toolchain

In scope: repository configuration, assembly boundaries, build metadata, headless diagnostics and self-test, Godot presentation shell, tests, Windows export definition, engineering scripts, and review evidence.

Explicitly out of scope: all biological simulation, cells, fields, regions, biological time/RNG, genome/metabolism/movement/ecology, biological persistence, adaptive fidelity, learning, compute plugins, remote services, mod execution, and fake-life animation.

## Later phases

Phase 0.2 and later work is deferred. Nothing in this document authorizes implementation beyond Phase 0.1.
